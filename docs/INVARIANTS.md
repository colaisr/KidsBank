# Инварианты KidsBank

Нельзя ломать без явного решения владельца и записи в спеке.

## 1. Это прототип

- Код расходный. Не строить «настоящий банк», API, БД, KYC, платёжный шлюз.
- Не путать этот репозиторий с будущим прод-репо.

## 2. Темы и экраны

- Один набор экранов на AMIO и Evoca. Банк = `data-theme`, не копипаста вёрстки.
- Тема и язык независимы.
- Переключатель темы и языка — внутри приложения, экран «Оформление», доступен в любой момент. Не прятать только в URL.

## 3. Локали

- Строки UI и демо-данных — только ключи i18n (`ui.*`, `demo.*`) в `src/locales/{hy,ru,en}.json`.
- В `src/data/` — id сущностей, не тексты на одном языке.
- Экран без трёх языков — не done.
- Смена языка синхронно перерисовывает хром и фикстуры.
- «Сбросить сценарий» в «Оформлении» сбрасывает `kidsbank.demo` и скин карты (`kidsbank.cardSkin` → «Океан»); банк, язык и роль не меняются.

## 4. Продукт

- База — концепт Surf. Сужать или раздувать baseline молча нельзя.
- Два кабинета: ребёнок и родитель. Переключатель роли ≠ переключатель банка.
- После change PlanDocs описывают актуальное «как задумано». `/opsx:archive` без выравнивания `01` / `02` / `17` / `19` (что затронуто) запрещён.

## 5. Секреты и git

- Не коммитить `.env`, ключи, пароли.
- `git push --force` в основную ветку запрещён, когда remote появится.

## 6. Presenter value sheets (демо для инвестора)

- Экраны показа с продуктовой механикой **должны** иметь muted ℹ️ → bottom sheet (ценность ребёнку / банку / сценарий), если не обоснован skip в change.
- Copy — `ui.presenter.*` в `presenter.{hy,ru,en}.json`, не хардкод.
- Пропуск уместен для: `/child/profile`, layout-shell'ов, модалок. Новая фича без sheet — только с явным обоснованием в proposal.
