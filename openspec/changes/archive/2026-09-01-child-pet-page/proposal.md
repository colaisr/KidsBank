## Why

Таб **«Питомец»** в нижней навигации с фазы 2 ведёт на заглушку. Для показа инвестору и банку нужен живой экран по макету **AMIO Junior** (`R-amio-junior-pet`) и **продуктовая история**: питомец — не отдельная игра, а **ежедневный повод вернуться в банк** и **мягко повторить финансовые привычки** (заработал ★ → потратил осознанно → не забыл про цель).

Это **явная дельта от Surf B5** (маскот-чат): тамагочи-цикл + **финансовый loop** (уход стоит ★ из заданий) + связь с B4 (бонус после подтверждения задания родителем).

**Не ломать:** инварианты [`docs/INVARIANTS.md`](../../../docs/INVARIANTS.md) — одна вёрстка AMIO/Evoca, hy/ru/en, `kidsbank.demo` + сброс, без бэкенда; флоу заданий/целей/переводов сохраняется.

## What Changes

- Экран `/child/pet` по макету: шапка, бейдж **уровень + имя**, речевой пузырь, персонаж, три progress-bar, три кнопки ухода.
- **Тамагочи (демо-ускоренный):** revisit-decay при возврате на таб; level-up за одно действие (+10 XP).
- **Финансовый loop:** уход **стоит** ★ (корм 5, игра 8, сон 3); ★ только из заданий (B4). Недостаточно ★ → кнопка disabled, пузырь ведёт на `/child/tasks`.
- **Мост к продукту:** после подтверждения задания родителем — `taskBuff` (одно бесплатное действие ухода); пузырь-навигатор на цели при «счастливом» питомце.
- **Презентерский бейдж** (замаскированный ℹ️ у бейджа уровня): по тапу — bottom sheet с таблицей ценности для ребёнка / банка / сценарием показа 90 с. Не часть «клиентского» UX, но видна на демо.
- Состояние в `kidsbank.demo` (`pet` + `taskBuff`); сброс → baseline.
- i18n hy/ru/en: `ui.pet.*`, `demo.pet.*`.

### Non-goals

- Чат маскота B5, витрина B2, игра B3 — отдельные changes.
- Родительский кабинет питомца, push, несколько питомцев, магазин, реальные деньги за корм.
- Питомец **не начисляет** ★ (только тратит и даёт XP/уровень).
- Кастомное имя питомца ребёнком.

### Acceptance

- `/child/pet`: уровень 3 • Кекс, 80/65/40, «Покорми меня!»; кнопки показывают **стоимость** `5 ★` / `8 ★` / `3 ★`.
- **Покормить** при балансе ≥5 → сытость ↑, −5 ★, level 4 + плашка; при балансе &lt;5 → disabled + пузырь «заработай в заданиях».
- Родитель подтверждает задание → у ребёнка `taskBuff` → одно действие ухода бесплатно.
- Счастливый питомец → пузырь с ссылкой на `/child/goals`.
- Revisit таба → шкалы просели без ожидания.
- ℹ️-бейдж → sheet с продуктовой таблицей (ребёнок / банк / сценарий).
- hy/ru/en; AMIO + Evoca; сброс; `npm run build` проходит.
