## Why

Young totem was a static placeholder. Kids 6–10 need a friendly Leo mascot they want to tap, with light motion.

## What Changes

- Redesigned chibi lion «Лео» (large eyes, warm gold palette, soft mane).
- Three CSS animations: idle breathe + glow, periodic blink, tap bounce.
- Totem screen: hero Leo, «Поиграть» / «Поговорить» demo bubbles (full game later).
- Dock lion uses idle animation.

### Non-goals

- Star costs, full pet simulation (teen `/child/pet` unchanged).

### Acceptance

- Young dock + `/child/young/totem`; hy/ru/en; `prefers-reduced-motion`; `npm run build`.

## Capabilities

- `child-young-totem-leo` (new)
