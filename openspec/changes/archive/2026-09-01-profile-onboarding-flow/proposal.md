## Why

Во время презентации нужно показать будущий онбординг: выбор роли (ребёнок / родитель) и возраста ребёнка — без замены текущего переключателя роли в настройках. Вход с карточки **Давид** в «Настройках профиля» даёт презентеру отдельный сценарий «как будет при первом входе», пока логика приложения не зависит от выбранного возраста.

Это **явная дельта от Surf** (персонализация по возрасту в концепте Surf) — сейчас только визуальный прототип двух шагов для показа.

**Не ломать:** инварианты [`docs/INVARIANTS.md`](../../../docs/INVARIANTS.md) — одна вёрстка AMIO/Evoca, hy/ru/en, `RoleToggle` в профиле остаётся, без бэкенда и без записи возраста в `kidsbank.demo`.

## What Changes

- Тап на карточку ребёнка (Давид) на `/child/profile` открывает экран **«Выберите роль»** (родитель / ребёнок) по макету.
- Тап **«Родитель»** → навигация в кабинет родителя (`/parent`), как при переключателе роли.
- Тап **«Ребёнок»** → экран **«Возраст ребёнка»** с пятью диапазонами (6–8 … 14–17), прогресс-индикатор шага 2, кнопка «Продолжить».
- Выбор возраста **не** меняет демо-состояние, задания, лимиты и стиль — только локальный UI state на экране.
- После «Продолжить» на экране возраста — возврат в кабинет ребёнка (главная `/child`).
- i18n hy/ru/en: `ui.onboarding.*` (или `ui.profile.onboarding.*`).
- Маршруты внутри child shell, без таб-бара на этих экранах (полноэкранный флоу).
- На экране **«Возраст ребёнка»** — muted **ℹ️** (как на заданиях, питомце и т.д.) → presenter value sheet: ценность для ребёнка / банка / сценарий показа (`ui.presenter.sheets.onboarding-age` в `presenter.{hy,ru,en}.json`).

### Non-goals

- Замена или удаление `RoleToggle` в настройках профиля.
- Сохранение возраста в `localStorage` / `kidsbank.demo`.
- Влияние возраста на контент, лимиты, задания, тему TEENZ vs Junior.
- Полный онбординг (регистрация, KYC, несколько детей).
- Presenter sheet на экране выбора роли (шаг 1) — только на экране возраста, где продуктовая история персонализации.

### Acceptance

- `/child/profile` → тап на Давид → «Выберите роль» с логотипом банка, двумя карточками и подписью.
- «Родитель» → `/parent`; «Ребёнок» → «Возраст ребёнка» с back на выбор роли.
- На экране возраста ℹ️ → sheet с таблицей ценности и сценарием показа (как P0-экраны).
- На экране возраста можно выбрать любой диапазон; «Продолжить» → `/child`; повторный вход в флоу не «помнит» возраст глобально.
- `RoleToggle` в профиле работает как раньше.
- hy/ru/en; AMIO + Evoca; `npm run build` проходит.
