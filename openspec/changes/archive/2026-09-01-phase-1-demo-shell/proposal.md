## Why

Фаза 0 закрыта: есть PlanDocs, роли и OpenSpec, но приложения в `src/` нет. Для любого демо инвестору и банкам нужна живая оболочка — переключение бренда, языка и кабинета без перезагрузки. Фаза 1 из [`PlanDocs/19-work-plan.md`](../../../PlanDocs/19-work-plan.md) — минимальный каркас, на который лягут экраны Surf в фазах 2–5.

## What Changes

- Инициализация Vite + React + TypeScript + Tailwind в `src/`.
- Мобильный phone-frame layout (узкая колонка, viewport под телефон).
- Система тем: `data-theme="amio|evoca"` с CSS-токенами по [`PlanDocs/17-theme-bank-1.md`](../../../PlanDocs/17-theme-bank-1.md) и [`17-theme-bank-2.md`](../../../PlanDocs/17-theme-bank-2.md).
- i18next: локали `hy`, `ru`, `en`; каталоги `src/locales/*.json` с ключами `ui.*` и `demo.*`.
- Демо-сущность ребёнка по id в `src/data/`; имя и прочие строки — только через i18n.
- Персистентность: `localStorage` + query `?bank=&lang=`; синхронизация при старте и при смене.
- Экран **«Оформление»**: переключение банка (AMIO / Evoca) и языка (Հայերեն / Русский / English); доступен с любого экрана (шапка или настройки).
- Переключатель **роли** ребёнок / родитель — отдельно от банка и языка; два пустых шелла-экрана с заголовком кабинета.
- Шрифты с покрытием латиницы, кириллицы и армянского.

**Surf baseline** — инфраструктура показа (темы, языки, кабинеты, «Оформление») по конституции; контент главной ребёнка — фаза 2, не здесь.

### Non-goals

- Экраны Surf (карта, копилка, задания, переводы) — фазы 2–5.
- Бэкенд, auth, API, БД.
- Evoca Dark (опция позже).
- Деплой и публичный URL — фаза 6.
- Нативные приложения, SEO, прод-архитектура.

### Acceptance

- AMIO ↔ Evoca и hy ↔ ru ↔ en переключаются **без полной перезагрузки страницы**; визуал и `demo.*` обновляются сразу.
- На шелле отображается демо-имя ребёнка из `demo.*`; при смене языка имя меняется синхронно с UI.
- Переключатель роли показывает пустой шелл «ребёнок» или «родитель» в активной теме.
- «Оформление» достижимо с главного шелла в один тап.
- Обе темы и три языка на узком viewport (~390px); инварианты [`docs/INVARIANTS.md`](../../../docs/INVARIANTS.md) не нарушены.

## Capabilities

### New Capabilities

- `app-shell`: Vite/React/TS/Tailwind scaffold, phone-frame layout, базовый роутинг, шрифты hy/ru/en.
- `theme-system`: `data-theme` amio/evoca, CSS-переменные токенов банков, перекраска без unmount.
- `i18n`: i18next, каталоги `hy|ru|en`, ключи `ui.*` / `demo.*`, синхронная смена UI и фикстур.
- `preferences`: чтение/запись `localStorage` и `?bank=&lang=`, инициализация при старте.
- `appearance`: экран «Оформление» — выбор банка и языка, всегда доступен из приложения.
- `role-cabinets`: переключатель роли и два пустых шелла (ребёнок / родитель), независимо от темы и языка.

### Modified Capabilities

- (нет — `openspec/specs/` пуст, это первый change)

## Impact

- **Новые файлы**: `src/` (приложение), `src/locales/`, `src/data/`, конфиги Vite/Tailwind/TS, `package.json` scripts (`dev`, `build`, `preview`).

- **Инварианты**: один набор экранов, темы через CSS, строки только i18n, «Оформление» внутри приложения, роль ≠ банк.
