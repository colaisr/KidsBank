## Why

За время разработки детского кабинета главная родителя (`/parent`) **деградировала**: контент не прокручивается (нет scroll-контейнера как у `ChildShell`), визуально «разъехалась» шапка и секции, а переключение банка меняет **раскладку** быстрых действий (сетка AMIO vs вертикальный feed Evoca) — хотя по инварианту «одни экраны, банк = CSS-тема» должен меняться только цвет.

Для живого демо родитель — ключевой сценарий (перевод, задание, лимит, подтверждение). Сейчас экран неудобен и выглядит недоделанным на фоне отполированного детского кабинета. Нужен целевой редизайн layout/shell без изменения бизнес-логики.

**Не ломать:** инварианты [`docs/INVARIANTS.md`](../../../docs/INVARIANTS.md); все секции и действия `/parent` (баланс, 4 quick actions, задания, цели, траты); presenter sheet `parent-home`; переключение банка только через токены.

## What Changes

- **Scroll-shell:** обёртка родительского кабинета с `overflow-y-auto` и корректной flex-цепочкой (`PhoneFrame` → shell → scroll area), как у ребёнка — весь контент ниже фиксированной шапки прокручивается.
- **Единая IA и layout:** одна и та же структура секций и сетка быстрых действий для AMIO и Evoca; **BREAKING** — убираем theme-specific раскладку (grid vs feed) из `index.css`.
- **Визуальная полировка:** взрослый banking-dashboard по `17` — компактная hero-зона с балансом, карточки секций, ритм отступов, типографика `font-heading`; только токены `--kb-*` / Tailwind theme, без хардкода цветов банка.
- **Тема = только палитра:** при смене `data-theme` меняются primary, градиент шапки, фон, акценты; порядок, размеры и расположение элементов **идентичны**.
- **Мелкие UX-улучшения без смены данных:** sticky `AppHeader`, фон `bg-surface-muted` для контента, единообразные заголовки секций, улучшенные empty states — в рамках существующих i18n-ключей.

### Non-goals

- Новые секции, табы или роуты (`/parent/tasks` и т.п.).
- Изменение демо-логики (переводы, задания, лимиты, модалки).
- Kids-скин для родителя; маскот; фаза 4 (инструменты).
- Evoca Dark.
- Presenter copy — sheet `parent-home` остаётся, тексты не переписываем.

### Acceptance

- На `/parent` при длинном контенте (много заданий/целей) страница **прокручивается** до нижней секции «Траты» на iPhone-ширине.
- AMIO ↔ Evoca: **одинаковая** раскладка (сетка 2×2 quick actions, те же секции); отличаются только цвета/градиенты токенов.
- hy / ru / en — без обрезания длинных строк (армянский).
- Все quick actions и секции работают как сейчас; `npm run build` проходит.
- Сброс сценария и переключение роли не затронуты.
