## Why

Экран `/child/transactions` сейчас — плоский список без макета Surf: нет градиентной шапки, фильтров «Все / Пополнения / Траты», группировки по дням, иконок категорий и единой линии **AMD + ★**. Для показа инвестору история выглядит как техничный лог, а не как инструмент финграмотности и «разговора дома». Прототип (макет) задаёт целевый UI; change закрывает дельту от Surf baseline в табе «Транзакции».

**Не ломать:** инварианты [`docs/INVARIANTS.md`](../../../docs/INVARIANTS.md) — одна вёрстка AMIO/Evoca, три языка, `kidsbank.demo` + сброс, без бэкенда, presenter sheet на экране.

## What Changes

- **Шапка как на макете:** градиент `--kb-header-gradient`, звезда слева → `/child/goals`, заголовок «Транзакции», **ℹ️ presenter sheet** (`child-transactions`) и чат → настройки презентера.
- **Фильтры:** сегмент «Все» / «Пополнения» / «Траты» — переключают список без смены роута.
- **Группировка:** блоки «Сегодня» / «Вчера» / «Ранее» (reuse `getRelativeDayGroup` как на копилке).
- **Карточки операций:** цветные иконки по типу (задание ✓, QR, кэшбэк, перевод, копилка…), подпись с временем («Сегодня, 14:30»).
- **Единая история AMD + ★:** новый тип `taskReward` в `transactions[]`; подтверждение задания родителем добавляет строку «Задание: … +N ★»; QR-покупки — `spend` с `merchantKey` («Оплата по QR • Sweet Shop»).
- **Сводка периода** (механика ценности): под фильтрами — чип «На этой неделе: +X AMD, −Y AMD, +Z ★» по видимым операциям; учит ребёнка «получил vs потратил» без отдельного аналитики-экрана.
- **Демо-сид:** богатый набор транзакций (сегодня/вчера) по макету для первого открытия и сброса сценария.
- **Presenter copy:** расширить `child-transactions` — ценности «две валюты», «заработал vs потратил», сценарий демо (фильтры → сводка → Hub → новая строка).

### Non-goals

- Аналитика по категориям, графики, экспорт, push-уведомления о тратах.
- Строки ★ за уход питомца / перенос ★ на цель (только `taskReward` при confirm задания).
- Изменение родительского превью транзакций (оставляем как есть).
- Реальный QR, категоризация из процессинга.

### Acceptance

- Таб «Транзакции»: шапка, фильтры, сводка, группы по дням, карточки с иконками — hy/ru/en, AMIO и Evoca, одна вёрстка.
- Фильтр «Пополнения» скрывает траты и ★; «Траты» — пополнения и ★; «Все» — полная лента.
- Confirm задания родителем → новая строка `taskReward` с ★ в истории ребёнка.
- Hub → демо-покупка → новая строка `spend` с merchant; сводка обновляется.
- ℹ️ открывает обновлённый presenter sheet с тремя блоками и сценарием.
- Сброс сценария восстанавливает сид-историю; `npm run build` проходит.
