## Why

Банки и вдохновитель проекта запрашивают расширение **кабинета родителя** за рамки Surf B1: не только деньги и задания, но и **где ребёнок** и **где были траты по карте** на одном экране. Прототип остаётся демо без бэкенда; нужен убедительный живой сценарий для переговоров (в т.ч. геолокация ведущего на preview по HTTPS).

## What Changes

- **Родительская зона:** общая шапка с **профилем / выбором ребёнка** (массив детей в модели, в сиде один — Давид); sheet со списком из одного выбранного пункта.
- **`/parent`:** после секции быстрых действий 2×2 — **строка «Геолокация»** со статусом (нейтральный при live GPS, школьный сид при fallback) → `/parent/geolocation`.
- **`/parent/geolocation`:** карта **Leaflet** + светлые OSM-совместимые тайлы (без Google); пин ребёнка; пины `spend` из demo transactions (+ при необходимости доп. сид); тег места; нижний sheet (статус, relative «обновлено N назад», online); кнопки **Сохранённые места** и **Места оплат** (оба открывают sheet); тап по пину траты = карточка как в «Местах оплат»; тап по месту в списке — фокус на карте без смены «текущей» позиции ребёнка.
- **Live GPS (ведущий):** при разрешении браузера — позиция ребёнка = текущая геолокация, якорь для смещений сохранённых мест и трат; copy **нейтральное** («текущее местоположение»), школа только в сохранённых местах. При отказе/ошибке — **fallback** на фиксированный сид (Ереван, школа в тексте).
- **Presenter:** новый `parent-geolocation`; доп. demo step в `parent-home`.
- **PlanDocs (при archive):** `01` (родитель), `02` (дельта roadmap), `references/README` (`R-parent-roadmap` — внутренний макет от stakeholder).

### Non-goals

- Реальный трек с устройства ребёнка, геозоны, push, SOS.
- Google Maps / Mapbox billing, ключи в репозитории.
- Редактирование сохранённых мест родителем; второй ребёнок в сиде; переключатель сценариев «школа/дом».
- Offline-карта без сети (тайлы требуют интернет).

### Acceptance

- hy / ru / en: все новые строки через i18n; presenter copy в трёх языках.
- AMIO и Evoca: одна IA, только токены темы; карта и маркеры не используют kids card-skin.
- На HTTPS preview: разрешение геолокации → нейтральный статус, пины трат рядом с якорем; отказ → fallback-сид.
- Spend-пины согласованы с `spend` в demo state; тап открывает merchant, AMD, время.
- `npm run build` проходит; инварианты `docs/INVARIANTS.md` (нет секретов, одна вёрстка двух банков).

## Capabilities

### New Capabilities

- `parent-geolocation`: экран карты, Leaflet, GPS/fallback, sheets мест и оплат, маршрут `/parent/geolocation`.

### Modified Capabilities

- `parent-home`: строка входа, синхронный статус, родительская шапка с выбором ребёнка, опционально чуть компактнее 2×2 (без смены состава действий).
- `demo-state`: якорь геолокации, сохранённые места, привязка spend → координаты (fallback), `updatedAt`.
- `presenter-value-sheets`: `parent-geolocation` + шаги `parent-home`.
- `app-shell`: вложенные маршруты родителя (`ParentShell` + `Outlet`).

## Impact

- **Зависимости:** `leaflet`, `react-leaflet`, `@types/leaflet` (dev).
- **Код:** `ParentShell`, `ParentHomePage`, новые страницы/компоненты карты, `demoBaseline`, `App.tsx`, `presenterSheets` + `presenter.*.json`, локали `ui.*` / `demo.*`.
- **Спеки:** delta перечисленных capabilities.
- **Деплой:** без env для карт; tile URL публичный с атрибуцией.
