## Why

Экран `/child/tasks` сейчас — простой список `TaskRow` без статистики, дедлайнов и визуала из макета AMIO Junior. Для показа инвестору нужен полноценный сценарий B4 «задания vs своё дело»: ребёнок видит прогресс (заработано ★, выполнено), карточки с наградой и дедлайном, чекбокс справа; родитель **создаёт** задания и **подтверждает** выполнение.

Это явная дельта от фазы 3 (механика ★ уже есть) — доводим UI и продуктовую модель до макета, не меняя экономику звёзд.

**Не ломать:** инварианты [`docs/INVARIANTS.md`](../../../docs/INVARIANTS.md) — одна вёрстка, три языка, `kidsbank.demo` + сброс, без бэкенда; флоу «ребёнок отмечает → родитель подтверждает → ★» сохраняется.

## What Changes

- Редизайн `/child/tasks` по макету: шапка «Задания», две карточки статистики (заработано ★ / выполнено заданий), список карточек с бейджем награды, дедлайном «до HH:MM» и чекбоксом справа; выполненные — зачёркнутый заголовок и зелёный чек.
- Расширение модели задания: `dueTime` (HH:MM), `templateId` для i18n; lifetime-статистика `taskStats.starsEarned` и `taskStats.tasksCompleted`.
- Обновление baseline: 5 заданий как на макете (4 активных поручения + 1 выполненное бытовое, напр. «Помыть посуду»). Строка «Добавь новую цель» с макета **не** переносится в задания — это домен целей (`/child/goals`).
- Родитель может **добавить задание** с главной: модалка с шаблоном, наградой в ★ и дедлайном → новое задание в `open` у ребёнка.
- Превью заданий на главной ребёнка — компактная версия новой карточки (первые 2).
- i18n hy/ru/en: `ui.tasks.*` (статистика, дедлайн, страница), `demo.tasks.*` (новые шаблоны).

### Non-goals

- Редактирование/удаление заданий родителем, несколько детей, push-уведомления.
- Свободный текст задания (только шаблоны из каталога — демо).
- Изменение флоу целей/обмена ★ на AMD; создание целей родителем.
- Поручения про цели («добавь цель») в каталоге шаблонов заданий.
- Отдельный роут `/parent/tasks` — создание с главной родителя.

### Acceptance

- Ребёнок: `/child/tasks` — статистика 860 / 31, 5 карточек как на макете; тап чекбокса переводит `open`→`inProgress`→`waitingParent`; выполненное задание зачёркнуто с зелёным чеком.
- Родитель: кнопка «Задание» на `/parent` → модалка → новое задание появляется у ребёнка; подтверждение `waitingParent` начисляет ★ и увеличивает счётчики.
- hy/ru/en; AMIO и Evoca — одна вёрстка, токены темы; сброс сценария восстанавливает baseline; `npm run build` проходит.

## Capabilities

### New Capabilities

- `child-tasks-page`: полноэкранный список заданий ребёнка — статистика, карточки, дедлайны, чекбокс-интеракция.
- `parent-task-management`: родитель создаёт задание из шаблона с наградой и дедлайном.

### Modified Capabilities

- `task-flow`: дедлайны, lifetime-статистика, чекбокс-интеракция на странице заданий.
- `parent-home`: быстрое действие «Задание» и модалка создания.
- `demo-state`: поля `dueTime`, `templateId`, `taskStats`; расширенный baseline заданий.
- `child-home`: превью заданий использует новый компактный вид карточки.
