## Why

Фаза 2 закрыта: главная ребёнка показывает счета, звёзды, задания и цели, но без живой экономики и без кабинета родителя. На показе инвестору нужны сценарии Surf B1 (деньги, лимиты, траты) и B4 (задание → подтверждение → награда → цель → AMD) — иначе демо остаётся статичной витриной.

Фаза 3 из [`PlanDocs/19-work-plan.md`](../../../PlanDocs/19-work-plan.md): переводы родитель↔ребёнок, лимиты, история трат у родителя, полный флоу заданий и звёзд, живая главная родителя в теме банка.

**Не ломать:** инварианты [`docs/INVARIANTS.md`](../../../docs/INVARIANTS.md) — одна вёрстка, три языка, `kidsbank.demo` + сброс, без бэкенда.

**База:** Surf baseline B1 + B4. Не изобретать взрослое ДБО.

## What Changes

- Расширение `kidsbank.demo`: лимиты карты, история операций, кошелёк родителя (демо), статусы заданий с интерактивом.
- **Задания (B4):** ребёнок принимает → отмечает выполненным → родитель подтверждает → ★ на баланс; перенос ★ на цель; при достижении цели — обмен на AMD на карту.
- **Деньги (B1):** перевод родитель→ребёнок (карта/копилка) и ребёнок→родитель; лимит на карту — поставить/снять; родителю видна история трат ребёнка.
- **Главная родителя:** AMIO — сетка быстрых действий; Evoca — feed-карточки; одна IA (перевод, лимит, траты, ожидающие задания).
- **Транзакции ребёнка:** `/child/transactions` — список из демо-состояния вместо заглушки.
- **Настройки презентера:** иконка чата (правый верхний угол на всех экранах ребёнка) → `/child/profile` — банк, язык, роль, сброс на одной странице; стрелка «назад» возвращает на экран, с которого зашли.
- i18n hy/ru/en для всех новых экранов и демо-операций.

### Non-goals

- Маскот-чат, витрина инструментов, игра — фазы 4–5.
- Реальные платежи, KYC, push-уведомления.
- Несколько детей в семье — один демо-ребёнок (Давид).

### Acceptance

- Полный сценарий: принять задание → выполнить → родитель подтверждает → ★ начислены → перенести на цель → цель достигнута → AMD на карту.
- Перевод родитель→ребёнок и обратно меняет балансы; лимит блокирует «трату» в демо; родитель видит историю.
- `/parent` в AMIO (сетка) и Evoca (feed) — одна IA, разный визуал токенами/компонентами, не форк роутов.
- hy/ru/en; «Сбросить сценарий» восстанавливает всё демо-состояние; `npm run build` проходит.
- С любого экрана ребёнка: чат → настройки → смена банка/языка → «назад» на тот же экран.

## Capabilities

### New Capabilities

- `parent-home`: главная родителя — переводы, лимиты, траты, очередь подтверждения заданий.
- `money-flow`: переводы родитель↔ребёнок и лимиты карты в демо-состоянии.
- `task-flow`: интерактивный цикл заданий и звёзд (принять → подтвердить → ★ → цель → AMD).
- `child-transactions`: история операций ребёнка на `/child/transactions`.

### Modified Capabilities

- `demo-state`: транзакции, лимиты, кошелёк родителя, мутации экономики звёзд.
- `role-cabinets`: родительский шелл — живая панель вместо заглушки.
- `child-home`: задания и цели интерактивны; фаза-2 «display-only» снимается.
- `child-nav`: чат-иконка → настройки с любого экрана; back из профиля.
- `appearance`: `DemoSettingsPanel` на профиле и `/appearance`; чат как вход в настройки ребёнка.
