# 17 — Design guidelines

Статус: актуален (2026-09-01). Общие правила. Палитры банков — в theme-файлах.

## 1. Принципы

- Телефон first. Десктоп — только чтобы открыть; layout как телефон (узкая колонка / frame допустим).
- Плавность: переходы экранов и смена темы/языка без полной перезагрузки «вспышкой пустого белого», если можно анимировать.
- Красота важнее плотности банковского «кабинета 2014».
- Один primary на экран.
- Армянский длиннее: не верстать впритык под русский.

## 2. Экран «Оформление»

Доступен **всегда**: пункт в профиле/настройках + быстрый вход с главной или из шапки.

На экране:

1. Банк: AMIO / Evoca (переключает `data-theme`).
2. Язык: Հայերեն / Русский / English (переключает locale и все `demo.*`).
3. Опционально позже: Evoca Dark.

Не смешивать с переключателем роли (ребёнок / родитель).

## 3. Кабинеты

Одинаковая информационная архитектура (табы Surf). Визуал:

- родитель — ближе к взрослому приложению банка;
- ребёнок — kids-скин той же палитры.

См. [`17-theme-bank-1.md`](17-theme-bank-1.md), [`17-theme-bank-2.md`](17-theme-bank-2.md).

## 4. Motion

Короткие ease, 200–350ms. Смена темы — перекраска токенов, не unmount всего дерева без нужды.

## 5. Шрифты

Покрывать латиницу, кириллицу, армянский. Evoca: Nomixa (или близкий grotesk) + Montserrat; иначе Noto Sans / Noto Sans Armenian. `dir=ltr` для всех трёх языков.

## 6. Presenter value sheets (ℹ️ для показа)

На экранах демо — **маленький muted ℹ️** рядом с заголовком экрана или секции. По тапу — bottom sheet с тремя блоками: ценность для ребёнка, для банка, короткий сценарий показа. Copy в `src/locales/presenter.*.json`, не хардкод.

**Размещение:**

- **Экранный ℹ️** (глобальный sheet страницы) — в кластере `HeaderPresenterActions`: **сразу перед** иконкой чата/настроек (`DemoSettingsLink`), не у центрального заголовка.
- `ChildHomeHeader`, `ChildTransactionsHeader` — заголовок по центру; ℹ️ + чат справа (`variant="onGradient"`).
- `ChildPageTitle` — `<h1>` слева/центр; `HeaderPresenterActions` справа (ℹ️ перед чатом).
- `AppHeader` (родитель) — ℹ️ перед переключателем роли и «Оформление».
- **Секции на главной** — компактный бейдж у `<h2>` (`HomeSectionHeading`, `AccountsSection`); объясняют бизнес-ценность блока, не дублируют экранный sheet.

**Стиль:** низкий контраст (`text-text-muted/50` или `text-white/40` на градиенте), **не** primary CTA, не конкурирует с навигацией.

**Когда пропускать:** служебные hub'ы (`/child/profile`), чистые layout-shell'ы, модалки и одноразовые формы — sheet родительского экрана достаточен. В proposal новой фичи — либо `presenterId` + copy в трёх языках, либо явный skip с причиной.

**Copy-стратегия:** `child-home` = глобальная ценность приложения (North Star); остальные id = «рычаг» конкретной механики, без повторения манифеста.
