## Как пользоваться

1. Не начинать фазу N+1, пока N не закрыта (исключение: хост в фазе 6 можно параллельно с 3–5, когда появится что показать).
2. Каждая фаза = один или несколько `/opsx:propose` → apply → **выровнять PlanDocs** → archive.
3. DoD любой фазы: обе темы, три языка, инварианты, сценарий можно прокликать на узком viewport, описание в `01`/`02`/`17` совпадает с тем, что в демо.

## Фаза 1 — Оболочка демо

**Статус: закрыта.**

Vite + React + TS + Tailwind. `data-theme`, i18next hy/ru/en, `localStorage` + `?bank=&lang=`. Экран **«Оформление»** (банк + язык) с любого места. Переключатель **роли** ребёнок/родитель (два пустых шелла). Шрифты с армянским. Узкая колонка под телефон. Default locale: `ru`.

OpenSpec: [`phase-1-demo-shell`](../openspec/changes/archive/2026-09-01-phase-1-demo-shell/). Локально: `npm run dev`. Preview: https://62-113-106-19.sslip.io/ (автодеплой при push в `main`, см. `16`).

## Фаза 2 — Главная ребёнка

**Статус: закрыта.**

Главная по макету AMIO Junior: карта/счёт, копилка AMD, баланс ★, задания и цели (отображение; механика ★ — фаза 3). Нижняя навигация: Главная · Цели · FAB · Транзакции · Питомец. Демо-состояние `kidsbank.demo` + «Сбросить сценарий» в «Оформлении». AMIO ≈ Junior, Evoca ≈ TEENZ, одна вёрстка.

OpenSpec: [`phase-2-child-home`](../openspec/changes/archive/2026-09-01-phase-2-child-home/).

## Фаза 3 — Деньги, лимиты, задания (B1 + B4)

**Статус: закрыта.**

Перевод родитель↔ребёнок (модалки + hub-демо). Лимиты поставить/снять (лимит на кнопке «Лимит»). История трат у родителя и ребёнка (`transactions[]`). Задание: принять → подтвердить родителем → ★; перенос ★ на цель → обмен на AMD (карта). Главная родителя: единая 2×2 раскладка, scroll-shell, тема = только цвет. Настройки презентера через иконку чата → `/child/profile` (`DemoSettingsPanel`). Сброс сценария с зелёной плашкой.

OpenSpec: [`phase-3-money-limits-tasks`](../openspec/changes/archive/2026-09-01-phase-3-money-limits-tasks/).

## Фаза 4 — Инструменты и маскот (B2 + B5)

Витрина обучения (вклады, кешбэк, накопительный, инвестиции, страхование, покупки) — демо-экраны, не реальные продукты. Чат маскота с репликами в `demo.*`; mark AMIO ≠ Evoca.

## Фаза 5 — Игра (B3)

Три возраста/уровня: лимонад → производство → корпорация. Решение влияет на игровой счёт; связь с «обменом баллов» из фазы 3, если уже есть.
