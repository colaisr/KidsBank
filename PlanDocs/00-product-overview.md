# 00 — Обзор продукта

Статус: актуален (2026-09-01). Конституция прототипа KidsBank.

## 1. Что это

Мобильный веб-прототип **детского / семейного банкинга** для показа инвестору и двум банкам (AMIO, Evoca). Выглядит как приложение на телефоне. Код расходный: после инвестиций проект соберут заново.

## 2. Формула

```text
концепт Surf (образование + игра + детские финансы)
+ два кабинета (ребёнок / родитель)
+ две темы (AMIO / Evoca)
+ три языка (hy / ru / en)
→ живой показ «как будто приложение работает»
```

Качество сейчас: красота UI, плавность переходов, демо основного функционала. Скорость важнее прод-архитектуры.

## 3. Продуктовая база

Канон: [Surf «Детский банкинг»](https://surf.ru/bank-for-kids/). Правило: сначала воссоздаём этот концепт. Дельты — только OpenSpec change. Подробная карта блоков: [`01-surf-baseline.md`](01-surf-baseline.md).

Цели Surf, которые держим:

1. Образовательный продукт, не копия взрослого банка в детском UI.
2. Родителю удобно, ребёнку интересно и понятно.
3. Простой интерфейс + геймификация + родительский контроль.

Вторичный кейс (не клон экранов): семейный банк SBI / «Свой круг», который Surf тоже делали.

## 4. Кабинеты и переключатели

| Что | Как |
|-----|-----|
| Роль | Ребёнок / родитель — отдельный контроль |
| Банк | AMIO / Evoca — тема, экран «Оформление» |
| Язык | hy / ru / en — там же в «Оформлении», всегда доступен |

Тема и язык независимы. Deep-link: `?bank=amio&lang=hy`.

## 5. Non-goals

Настоящие KYC и карты, платёжный шлюз, ЖКХ/кредиты взрослого ДБО, натив iOS/Android, сервер и БД, SEO.

## 6. Аудитория показа

- Инвестор: «это живое, красивое, семья пользуется».
- AMIO / Evoca: «вот как это выглядит в вашем бренде, в том числе на армянском».

Команда показа может не говорить по-армянски — поэтому язык переключается на любом экране вместе с демо-текстами.

## 7. Закрытые решения

- База = Surf.
- Два кабинета, две темы, три языка с дня 1.
