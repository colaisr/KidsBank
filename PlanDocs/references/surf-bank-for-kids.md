# Референс: Surf «Детский банкинг»

Канон продукта: [https://surf.ru/bank-for-kids/](https://surf.ru/bank-for-kids/)

## Цели (цитата смысла, не копирайт лендинга)

- Образовательный продукт, не взрослый банк в детском UI.
- Мышление про риск, не только копилка.
- Родителю удобно, ребёнку интересно.
- UI + геймификация + родительский контроль.

## Блоки

См. норматив [`../01-surf-baseline.md`](../01-surf-baseline.md).

## Вторичный кейс

Surf упоминают первый в России семейный банк для **SBI** («Свой круг» / START). Не обязательный клон экранов. Полезно как живой родственник: два приложения, копилка, задания, лимиты, маскот.
